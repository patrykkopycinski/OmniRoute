- **fix(admission):** Under `critical` resource pressure the chat gate now sheds only requests that could actually grow the heap. The blanket refusal 503'd every request — including a health ping — while the process still had headroom, so agent workers burned their retry budget on 5xx. One shared weight classifier (`src/shared/middleware/chatPressureWeight.ts`) judges declared body bytes, message count, tool count and a conservative structure-token estimate, treats an unmeasurable request (e.g. a chunked body) as heavy, and bounds the post-parse provider-work guards too, so a light request admitted at the gate is not refused one layer up. Pressure `503`s also return a derived `Retry-After` (episode duration, floored at 5s, capped at 120s) instead of a constant 5s, and the shed event now carries the severity, reason and heap numbers behind it.
